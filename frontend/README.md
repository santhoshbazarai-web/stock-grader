# Stock Grader — web

Next.js 15 (App Router, TypeScript) + Tailwind v4 + shadcn/ui.

```bash
npm install
npm run dev        # http://localhost:3000, expects the API at $API_URL (default http://localhost:8000)
npm run lint
npm run typecheck
```

Add shadcn components with `npx shadcn@latest add <component>` (config in `components.json`).
